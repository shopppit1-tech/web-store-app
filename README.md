# WEB STORE APP

Static GitHub Pages build for the public web-app directory.

The site is designed as a mobile-first catalog of web apps with direct links, app icons, favorites, and PWA installation support.

## GitHub Pages

After publishing from the `main` branch root, the site is available at:

https://shopppit1-tech.github.io/web-store-app/

This repository contains only the compiled static website and public app entries; no backend secrets are included.
